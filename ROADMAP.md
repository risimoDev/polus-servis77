# Полюс Сервис — Roadmap и статус проекта

## Стек
- **Лендинг**: чистый HTML5 / CSS3 / Vanilla JS (без фреймворков)
- **Бэкенд (в разработке)**: Node.js + TypeScript, Fastify 4, Prisma 5, PostgreSQL
- **Инфраструктура**: Nginx, Docker / docker-compose, Let's Encrypt

---

## Структура файлов

```
polus-servis77/
├── index.html              # Лендинг (единственная страница)
├── assets/
│   ├── css/style.css       # Все стили (~2200 строк)
│   ├── js/main.js          # Вся клиентская логика (~580 строк)
│   └── images/
│       └── logo2.svg       # Логотип (CorelDRAW, 300×300)
├── nginx/nginx.conf        # Готовая конфигурация Nginx
├── send.php                # Резервный обработчик формы (PHP, без бэкенда)
├── robots.txt
├── sitemap.xml
│
├── server/                 # Node.js API (в разработке)
├── src/                    # TypeScript-источники API
├── prisma/                 # ORM-схема и миграции
├── migrations/             # SQL-миграции
├── admin/                  # Панель управления (в разработке)
│
├── Dockerfile
├── docker-compose.yml
├── package.json
└── tsconfig.json
```
